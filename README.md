# Biofuel Game Research

A comprehensive research repo for a computer science class project —
building an educational 2D pixel-art game about biofuels in **C++**.

## Quick Start

Start with **[Agents.md](./Agents.md)** — the master development plan that
maps everything: tech stack, architecture, phases, and how research data
feeds into game mechanics.

Then browse the research docs:

| # | File | What's In It |
|---|------|-------------|
| — | [Agents.md](./Agents.md) | 🎮 **Game development master plan** (C++, engine decision, architecture, phases) |
| 01 | [Research/01-biofuel-fundamentals.md](./Research/01-biofuel-fundamentals.md) | What are biofuels? Types (ethanol, biodiesel, renewable diesel, biogas, SAF). The four generations. Key stats. Quick comparison table. |
| 02 | [Research/02-production-processes.md](./Research/02-production-processes.md) | How biofuels are made. Fermentation → ethanol. Transesterification → biodiesel. Anaerobic digestion → biogas. Pyrolysis, gasification, hydrothermal liquefaction. Process diagrams. |
| 03 | [Research/03-feedstock-and-crops.md](./Research/03-feedstock-and-crops.md) | What biofuels are made FROM. Corn, sugarcane, soy, palm, algae. Waste streams. Energy crops (switchgrass, miscanthus). Geographic distribution. Input requirements (fertilizer, water, pesticides). |
| 04 | [Research/04-energy-and-emissions.md](./Research/04-energy-and-emissions.md) | Energy content (BTU/gal comparisons). Fossil Energy Ratio. GHG reductions vs. fossil fuels. Water consumption. Dead zones. Land use change. Carbon debt payback times. Food vs. fuel. |
| 05 | [Research/05-economics-and-policy.md](./Research/05-economics-and-policy.md) | Market size and growth. Government policies (RFS, IRA, LCFS). Fuel prices. Cost breakdowns. The food vs. fuel debate. Key companies. International trade. |
| 06 | [Research/plans/06-game-design-ideas.md](./Research/plans/06-game-design-ideas.md) | Five game concepts: Fuel Farm, Carbon Rush, Biorefinery, Green Empire, Policy Simulator. Game mechanics with real data. Carbon debt mechanic. MVP scope and tech stack suggestions. |

If you want the raw facts for your game's data: **04-energy-and-emissions.md**
has all the BTU, GHG, and yield numbers.
