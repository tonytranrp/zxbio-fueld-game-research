# Biofuel Game Research

A comprehensive research repo for a computer science class project —
building an educational game about biofuels.

## Documents

| # | File | What's In It |
|---|------|-------------|
| 01 | [01-biofuel-fundamentals.md](./01-biofuel-fundamentals.md) | What are biofuels? Types (ethanol, biodiesel, renewable diesel, biogas, SAF). The four generations. Key stats. Quick comparison table. |
| 02 | [02-production-processes.md](./02-production-processes.md) | How biofuels are made. Fermentation → ethanol. Transesterification → biodiesel. Anaerobic digestion → biogas. Pyrolysis, gasification, hydrothermal liquefaction. Process diagrams. |
| 03 | [03-feedstock-and-crops.md](./03-feedstock-and-crops.md) | What biofuels are made FROM. Corn, sugarcane, soy, palm, algae. Waste streams. Energy crops (switchgrass, miscanthus). Geographic distribution. Input requirements (fertilizer, water, pesticides). |
| 04 | [04-energy-and-emissions.md](./04-energy-and-emissions.md) | Energy content (BTU/gal comparisons). Fossil Energy Ratio. GHG reductions vs. fossil fuels. Water consumption. Dead zones. Land use change. Carbon debt payback times. Food vs. fuel. |
| 05 | [05-economics-and-policy.md](./05-economics-and-policy.md) | Market size and growth. Government policies (RFS, IRA, LCFS). Fuel prices. Cost breakdowns. The food vs. fuel debate. Key companies. International trade. |
| 06 | [06-game-design-ideas.md](./06-game-design-ideas.md) | Five game concepts: Fuel Farm, Carbon Rush, Biorefinery, Green Empire, Policy Simulator. Game mechanics with real data. Carbon debt mechanic. MVP scope and tech stack suggestions. |

## Quick Start

If you only read one file, read **06-game-design-ideas.md** — it has the best
concept for a CS class project (Fuel Farm) with real numbers you can plug into
game mechanics.

If you want the raw facts for your game's data: **04-energy-and-emissions.md**
has all the BTU, GHG, and yield numbers.
